# Лабораторная работа 3 — Учебная платформа

Это самостоятельный проект React/Vite. Страница учебной платформы открывается сразу по основному адресу. Файлы прежней lab1 в проект не включены.

## Запуск

1. Распакуйте lab3.zip в отдельную папку lab3.
2. В VS Code выберите «Файл → Открыть папку» и откройте lab3, где находится package.json.
3. Откройте терминал и выполните:

```powershell
npm ci
npm run dev
```

4. Откройте адрес Local из терминала. Добавлять /lab3.html не нужно. Если порт 5173 занят, используйте тот порт, который указан в терминале.

## Сборка

```powershell
npm run build
npm run preview
```

## Структура

- index.html — главная страница.
- src/main.jsx — запуск React.
- src/Platform.jsx — сборка страницы и состояние поиска, фильтра и записи.
- src/components — меню, партнёры, карточки преподавателей, форма записи.
- src/data/lecturers.js — 10 преподавателей, 30 дисциплин, 300 тем лекций и 30 тарифов из задания.
- src/platform.css — оформление и адаптация под телефон.
- public/lecturers.png — фотографии из документа задания.

Используются React и React DOM, без дополнительных библиотек интерфейса. Vite используется для запуска и сборки.

Сохранены поиск, фильтр по дисциплине, раскрытие программ и выбор тарифа. Форма записи учебная: проверяет поля, но не отправляет данные на сервер.

Визуальные ограничения прежней версии сохраняются: комментарии Figma недоступны без входа; главная иллюстрация заменена коллажем из задания, логотипы партнёров представлены текстом. Полное совпадение с макетом пока не подтверждено.
